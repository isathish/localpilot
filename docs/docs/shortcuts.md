| Action | macOS | Windows / Linux | When |
|---|---|---|---|
| Open chat | <kbd>⌘⇧L</kbd> | <kbd>Ctrl⇧L</kbd> | |
| New chat | <kbd>⌘⇧⌥L</kbd> | <kbd>Ctrl⇧AltL</kbd> | |
| Run tasks in parallel | <kbd>⌘⇧⌥P</kbd> | <kbd>Ctrl⇧AltP</kbd> | |
| Inline edit | <kbd>⌘⌥K</kbd> | <kbd>CtrlAltK</kbd> | editor focused |
| Generate terminal command | <kbd>⌘⌥K</kbd> | <kbd>CtrlAltK</kbd> | terminal focused |
| Capture screenshot to chat | <kbd>⌘⌥⇧S</kbd> | <kbd>CtrlAlt⇧S</kbd> | |
| Explain selection | <kbd>⌘⇧E</kbd> | <kbd>Ctrl⇧E</kbd> | selection |

## Inside the chat

| Key | Action |
|---|---|
| <kbd>Enter</kbd> | Send |
| <kbd>⇧Enter</kbd> | New line |
| <kbd>⌘⇧Enter</kbd> / <kbd>Ctrl⇧Enter</kbd> | Send in a **new tab** (another agent, in parallel) |
| <kbd>Alt↑</kbd> / <kbd>Alt↓</kbd> | Previous / next chat tab |
| <kbd>Alt1</kbd> … <kbd>Alt9</kbd> | Jump to tab N |
| <kbd>←</kbd> / <kbd>→</kbd> / <kbd>Delete</kbd> / <kbd>F2</kbd> (tab focused) | Move between tabs / close / rename |
| <kbd>⌘</kbd>-click / <kbd>⇧</kbd>-click a tab · <kbd>⌘A</kbd> (tab focused) | Select several tabs (then ✕ / <kbd>Delete</kbd> closes them all) |
| <kbd>/</kbd> | Slash command picker |
| <kbd>@</kbd> | Mention picker |
| <kbd>↑</kbd> / <kbd>↓</kbd> / <kbd>Tab</kbd> | Navigate / accept picker |
| <kbd>↑</kbd> / <kbd>↓</kbd> (empty input) | Previous / next prompt from history |
| <kbd>Esc</kbd> | Close picker — or **stop the running agent** when no picker is open |
| <kbd>⌥Esc</kbd> / <kbd>AltEsc</kbd> | **Pause** the running agent after its current step / **resume** it |
| <kbd>Enter</kbd> (agent running) | *Add to this agent* — queue the message for its next step — or send in a new tab |
| <kbd>⌘L</kbd> / <kbd>CtrlL</kbd> | Focus the input |
| <kbd>⌘I</kbd> / <kbd>CtrlI</kbd> | Open the **@ Add context** menu |
| <kbd>Y</kbd> / <kbd>A</kbd> / <kbd>N</kbd> | Answer a permission prompt: allow once / allow for session / deny |
