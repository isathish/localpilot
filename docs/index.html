The AI coding agent that
runs on your machine

LocalPilot is an open-source coding agent for VS Code that works like Copilot, Cursor or Claude Code — reads your code, edits files, runs tests, reviews changes — but every token is generated by a model you run yourself with Ollama, LM Studio, llama.cpp, vLLM or Docker Model Runner. No account, no cloud, no telemetry.

Screenshots from a real session, not mock-ups

Every image below is a capture of LocalPilot v{{ site.version }} running in VS Code against a local qwen2.5-coder:7b. You can reproduce each one in a few minutes.

Every edit is reviewable and reversible

Each file the agent touches is snapshotted first. Click it in the Changes panel to open a side-by-side diff; accept or reject per file, or restore the whole chat to an earlier checkpoint. Edits show as +1 −1 cards right in the transcript.

Run agents in parallel

Type three tasks separated by | and each gets its own agent, its own tab and its own change set. The Agents panel shows what each one is doing; the status bar counts them. Keep or undo per agent when they finish.

Commands run in a terminal you can see

The agent's run_command calls execute in a branded LocalPilot Agent terminal through shell integration — live output, real exit codes, Ctrl+C on stop. Right-click any terminal for Explain output or Fix failed command.

The same agent in your shell

localpilot "fix the failing tests" runs the identical agent loop, tools, skills, memory and approvals from any terminal — streaming, with y/n/always prompts or --yes for scripts and CI.

Knows your hardware, manages your models

LocalPilot reads your RAM, cores and GPU memory, turns that into a model budget and marks every model fits / tight / too big. Install from a curated catalog into Ollama, Docker Model Runner or LM Studio with live progress; enable, disable, set default or remove with one click.

Setup finds what you already run

On first launch LocalPilot probes the usual ports and Docker containers, lists the models it finds, recommends one for agent work and lets you pick an approval preset. No server yet? One click installs Ollama and a starter model sized for your machine.

Features

What LocalPilot does

Built for local models from day one: tool calling with a prompt-based fallback for models without function calling, context management that keeps 8k–32k windows productive, and approval gates you control.

Agent mode

Reads, searches, edits, runs commands and diagnostics, then fixes its own mistakes — with approval prompts for anything risky.

Parallel agents

Run several tasks at once; each session is an independent agent. The Agents panel shows live status and every file each one touched.

Review, keep or undo

Every agent edit is snapshotted. Diff, keep or revert per file or per session — with changed lines highlighted in the editor.

Large-context management

Token budgeting per model: old tool outputs are pruned first, then the history is summarised — so 8k-context models still finish long tasks.

Skills & subagents

Reusable SKILL.md playbooks loaded on demand, plus explore / coder / reviewer / researcher subagents — or define your own.

Screenshots & images

Capture a selection, a window or the full screen, paste or drop images, and ask vision models to fix the UI bug they see.

Terminal & CLI

The agent runs commands in a branded terminal you can watch live; right-click any terminal to explain or fix its output. The localpilot CLI brings the whole agent — tools, skills, memory, approvals, undo — to your shell.

Web search & MCP

DuckDuckGo, SearXNG, Brave or Tavily search plus readable page fetch; plug in any MCP server and its tools appear automatically.

Inline completions

Ghost-text suggestions from FIM models such as qwen2.5-coder, codestral or starcoder2 — fast and fully offline.

One-click model setup

No model? LocalPilot starts or installs Ollama and downloads a smallest-first starter set sized to your RAM and GPU — an agent model, a tiny completion model and, with room to spare, a vision model.

Model manager & catalog

See what fits your machine, enable / disable, set default or remove installed models, and install from a curated catalog to Ollama, Docker Model Runner or LM Studio with live progress.

Automatic routing

Image turns go to a vision model, completions to the smallest FIM model, Plan mode to a reasoning model — and an offline model falls back to the best one available.

Deep VS Code integration

Sidebar and editor-tab chat, @localpilot chat participant, local models in Copilot's model picker, light-bulb fixes and commit messages.

Private by design

No accounts, no telemetry, no cloud. Your code only ever reaches the model servers you configure — on localhost by default.

Follows your rules

Automatically honours AGENTS.md, CLAUDE.md, .cursorrules and copilot-instructions.md — no migration needed.

Zero-config, Docker-ready

Finds Ollama, LM Studio, llama.cpp, vLLM, Docker Model Runner and model servers running in Docker containers on their own, adds them to your settings and picks the best tool-capable model that fits in memory. The Settings screen manages providers, approvals, completions, memory and MCP.

Why you can trust it

Open, local, verifiable

Open source, MIT

Every line is on GitHub, built and maintained by {{ site.author.name }}. The extension and the localpilot CLI are built from the same source; releases ship a VSIX with SHA-256 checksums.

Only talks to servers you configure

The provider list is yours. Defaults are localhost. No analytics SDK, no account, no update pings — the extension has zero network calls other than your model servers, MCP servers and the web tools you explicitly approve.

Tested against real models

The test suite runs inside a real VS Code and includes end-to-end runs against a live Ollama: the agent reads a file, edits it, runs the tests, works in parallel sessions and stops on request. Run npm test yourself.

Approvals you set

Terminal, file edit, delete and network actions each have an Ask / Allow / Block policy — presets Careful, Balanced, Autonomous. Every edit is undoable regardless of policy.

Works with your existing rules

AGENTS.md, CLAUDE.md, .cursorrules, .cursor/rules, .github/copilot-instructions.md, .claude/skills and .claude/agents are picked up automatically.

Honest about small models

A 7B model is not GPT-class. LocalPilot compensates with retries, text-protocol tool parsing, diagnostics loops and a completion nudge — and shows you every step so you can intervene.

FAQ

Questions, answered

Which models work best?

For agentic coding with tools: qwen2.5-coder:14b/32b, qwen3, devstral, llama3.3, mistral-small, gpt-oss. For inline completions: qwen2.5-coder:1.5b/7b-base, codestral, starcoder2. For screenshots: qwen2.5vl, llava, gemma3.

My model doesn't support tool calling. Does agent mode still work?

Yes. LocalPilot detects missing native tool support and switches to a prompt-based protocol, parsing tool calls out of the model's text. Quality depends on the model, but even 7B models handle it well.

Does any data leave my machine?

Only if you configure it to — for example a remote OpenAI-compatible endpoint, or the optional web search tool (which asks for approval by default). There is no telemetry and no account.

How is this different from the Copilot "bring your own key" option?

LocalPilot is a complete agent, not just a model provider. You get the agent loop, tools, parallel agents, change review, skills, subagents, screenshots and MCP — and it also registers your local models with VS Code's Language Model API so other extensions can use them.

Can I use my existing Claude Code / Cursor rules and skills?

Yes. CLAUDE.md, AGENTS.md, .cursorrules, .cursor/rules/*.mdc, .claude/skills, .claude/agents and .github/copilot-instructions.md are all picked up automatically.
