An AI teammate that lives on your computer

You describe a task in plain words. LocalPilot reads your project, changes the code, runs your tests and shows you exactly what changed. The AI model runs on your own machine, so your code stays with you.

See every change before it lands

The agent works on a copy of your project in its own git worktree. Open any changed file as a side-by-side diff, then apply it or discard it.

  • Keep or undo per file, inside or outside git

02 / 11 · Auto mode

It picks the right mode for every message

Ask a question and it answers read-only. Report an error and it debugs. Ask for a plan and it plans. Auto chooses the mode and the model, and tells you why.

03 / 11 · Parallel agents

Several tasks, several agents, one window

Split the work and LocalPilot starts an agent per task, each in its own tab and worktree, so their edits never collide.

  • Run one task on several models and keep the best
  • Apply or discard each agent's changes separately

  • Approve commands once, for the chat, or always

FAQ 09Questions

Common questions

Is LocalPilot free?

Yes. It is free and open source under the MIT license, with no paid tier, account or usage limit. Your only cost is the hardware you already own. It is an independent project by {{ site.author.name }}, not affiliated with any model or editor vendor.

Which models work best?

Automatic setup installs gemma4:e4b (or gemma4:e2b on machines with less memory). It calls tools and reads screenshots, so one model covers agent work and images. With more memory, qwen2.5-coder 14B or 32B, qwen3, devstral, gpt-oss and mistral-small are stronger agent models. For inline completions use qwen2.5-coder:1.5b, starcoder2 or codestral. After a few days, the Dashboard ranks your installed models by how they actually performed for you.

What hardware do I need?

A 7B model needs about 8 GB of RAM and runs on most recent laptops; 14B to 32B models want 16 to 32 GB. A GPU or Apple Silicon makes responses much faster but is not required. For very large mixture-of-experts models on modest RAM, use colibri, which streams the experts from disk.

Does any data leave my machine?

Your code and prompts go only to the model servers you configure, which are all localhost by default. A cloud provider you add receives what you send to its models. Two optional features make other requests: the skill registry fetches an index from GitHub at most once a day, and the web search and fetch tools follow localpilot.approvals.network. Both can be switched off. Dashboard metrics stay in ~/.localpilot/telemetry. See the privacy page.

Can I use OpenAI, Claude, Gemini or OpenRouter?

Yes, with your own API key. Settings → Providers → Cloud APIs has presets for OpenAI, Anthropic (Claude), Google Gemini, OpenRouter, Groq, Mistral, DeepSeek, xAI, Together, Fireworks, Cerebras, Hugging Face, NVIDIA NIM, Moonshot, Alibaba Qwen, Azure OpenAI and Ollama Cloud, plus the OmniRoute and LiteLLM gateways. A pasted key goes to your OS keychain. Cloud models are marked cloud; Auto, subagents and inline completions keep using local models unless you pick a cloud one. See Cloud models.

My model doesn't support tool calling. Does agent mode still work?

Yes. When a model has no native tool support, LocalPilot switches to a text protocol and reads the tool calls out of the model's reply. Results depend on the model, but 7B coder models handle it well.

Can I use my existing Claude Code or Cursor rules and skills?

Yes. CLAUDE.md, AGENTS.md, .cursorrules, .cursor/rules, .claude/skills, .claude/agents, .claude/settings.json permissions and hooks, .claude/commands and .github/copilot-instructions.md are all read without changes. See Claude Code compatibility.

How is this different from Copilot's "bring your own key"?

Bring-your-own-key swaps the model behind Copilot. LocalPilot is a complete agent: the loop, the tools, parallel agents, change review, skills, subagents, screenshots and MCP. It also registers your local models with VS Code's Language Model API, so other extensions can use them too.
