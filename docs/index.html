Features

Everything you expect from a frontier coding assistant

Built for local models from day one — tool calling with a prompt-based fallback, aggressive context management, and approval gates you control.

Agent mode

Reads, searches, edits, runs commands and diagnostics, then fixes its own mistakes — with approval prompts for anything risky.

Parallel agents

Run several tasks at once; each session is an independent agent. The Agents panel shows live status and every file each one touched.

Review, keep or undo

Every agent edit is snapshotted. Diff, keep or revert per file or per session — with changed lines highlighted in the editor.

Large-context management

Token budgeting per model: old tool outputs are pruned first, then the history is summarised — so 8k-context models still finish long tasks.

Skills & subagents

Reusable SKILL.md playbooks loaded on demand, plus explore / coder / reviewer / researcher subagents — or define your own.

Screenshots & images

Capture a screen region, paste or drop images, and ask vision models to fix the UI bug they see.

Inline edit & terminal

⌘⌥K rewrites a selection in place; in the terminal it turns plain English into a command you can review and run.

Web search & MCP

DuckDuckGo, SearXNG, Brave or Tavily search plus readable page fetch; plug in any MCP server and its tools appear automatically.

Inline completions

Ghost-text suggestions from FIM models such as qwen2.5-coder, codestral or starcoder2 — fast and fully offline.

Deep VS Code integration

Sidebar and editor-tab chat, @localpilot chat participant, local models in Copilot's model picker, light-bulb fixes and commit messages.

Private by design

No accounts, no telemetry, no cloud. Your code only ever reaches the model servers you configure — on localhost by default.

Follows your rules

Automatically honours AGENTS.md, CLAUDE.md, .cursorrules and copilot-instructions.md — no migration needed.

How it works

Up and running in three steps

Serve a model

Start any local server. LocalPilot auto-detects Ollama, LM Studio, llama.cpp and vLLM on their default ports.

ollama pull qwen2.5-coder:14b
ollama serve

Install LocalPilot

Download the VSIX and install it from the Extensions view or the command line.

code --install-extension localpilot.vsix

Pick a model and go

Open the LocalPilot sidebar, choose a model, and ask for a change. Review the diff, keep it, ship it.

⌘⇧L  open chat
⌘⌥K  inline edit

FAQ

Questions, answered

Which models work best?

For agentic coding with tools: qwen2.5-coder:14b/32b, qwen3, devstral, llama3.3, mistral-small, gpt-oss. For inline completions: qwen2.5-coder:1.5b/7b-base, codestral, starcoder2. For screenshots: qwen2.5vl, llava, gemma3.

My model doesn't support tool calling. Does agent mode still work?

Yes. LocalPilot detects missing native tool support and switches to a prompt-based protocol, parsing tool calls out of the model's text. Quality depends on the model, but even 7B models handle it well.

Does any data leave my machine?

Only if you configure it to — for example a remote OpenAI-compatible endpoint, or the optional web search tool (which asks for approval by default). There is no telemetry and no account.

How is this different from the Copilot "bring your own key" option?

LocalPilot is a complete agent, not just a model provider. You get the agent loop, tools, parallel agents, change review, skills, subagents, screenshots and MCP — and it also registers your local models with VS Code's Language Model API so other extensions can use them.

Can I use my existing Claude Code / Cursor rules and skills?

Yes. CLAUDE.md, AGENTS.md, .cursorrules, .cursor/rules/*.mdc, .claude/skills, .claude/agents and .github/copilot-instructions.md are all picked up automatically.

Is it on the Marketplace?

Releases ship as a VSIX on GitHub (Releases). Install with code --install-extension localpilot.vsix or via Extensions → … → Install from VSIX.
