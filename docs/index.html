Features

What LocalPilot does

Built for local models from day one: tool calling with a prompt-based fallback for models without function calling, context management that keeps 8k–32k windows productive, and approval gates you control.

Agent

  • Agent modeReads, searches, edits, runs commands and diagnostics, then fixes its own mistakes — with approval prompts for anything risky.
  • Parallel agentsSeveral tasks at once, each an independent session with its own tab, status and change set.
  • Review, keep or undoEvery edit is snapshotted. Diff, keep or revert per file or per session, with changed lines highlighted.
  • Skills & subagentsReusable SKILL.md playbooks loaded on demand, plus explore / coder / reviewer / researcher subagents — or your own.

Models & setup

  • One-click model setupNo model? LocalPilot installs or starts Ollama and downloads a smallest-first starter set sized to your RAM and GPU.
  • Model manager & catalogSee what fits, enable / disable, set default or remove models, and install from a curated catalog with live progress.
  • Automatic routingImages go to a vision model, completions to the smallest FIM model, Plan mode to a reasoning model; offline models fall back.
  • Zero-config, Docker-readyFinds Ollama, LM Studio, llama.cpp, vLLM, Docker Model Runner and model servers in containers on its own.

Context & tools

  • Large-context managementPer-model token budgets: old tool output is pruned first, then history is summarised — 8k-context models still finish long tasks.
  • Screenshots, images & browser viewCapture a selection, window, screen or web page; vision models fix the bug they see. A browser view inspects your dev server over DevTools.
  • Terminal & CLICommands run in a branded terminal you can watch; the localpilot CLI brings the whole agent to your shell.
  • Web search & MCPDuckDuckGo, SearXNG, Brave or Tavily search plus page fetch; any MCP server's tools appear automatically.

Editor & privacy

  • Inline completionsGhost-text from FIM models such as qwen2.5-coder, codestral or starcoder2 — fast and fully offline.
  • Deep VS Code integrationSidebar and editor-tab chat, @localpilot participant, local models in Copilot's model picker, light-bulb fixes, commit messages.
  • Follows your rulesHonours AGENTS.md, CLAUDE.md, .cursorrules and copilot-instructions.md — no migration.
  • Private by designNo accounts, no telemetry, no cloud. Your code only reaches the model servers you configure — localhost by default.

FAQ

Questions, answered

Which models work best?

For agentic coding with tools: qwen2.5-coder:7b/14b/32b, qwen3, devstral, gpt-oss, mistral-small. For inline completions: qwen2.5-coder:1.5b, codestral, starcoder2. For screenshots: qwen2.5vl, gemma3. The catalog in Settings → Models marks every size fits / tight / too big for your hardware and stars the recommended one.

I have never run a local model. How hard is the setup?

One click. When LocalPilot finds no model it offers Set up automatically: it installs Ollama (Homebrew, winget or the official script), downloads a coder model sized for your RAM/GPU — smaller models first, so you are productive in minutes — and configures itself. Bigger models are an explicit upgrade from the catalog.

Does it use one model for everything?

No. Routing picks per task: a vision model when a turn has images, the smallest fill-in-the-middle model for ghost-text completions, an optional reasoning model in Plan mode, and the best available model when your default is offline or disabled. Each can be pinned in Settings → Models → Routing.

My model doesn't support tool calling. Does agent mode still work?

Yes. LocalPilot detects missing native tool support and switches to a prompt-based protocol, parsing tool calls out of the model's text. Quality depends on the model, but even 7B models handle it well.

Does any data leave my machine?

Only if you configure it to — for example a remote OpenAI-compatible endpoint, or the optional web search tool (which asks for approval by default). There is no telemetry and no account.

How is this different from the Copilot "bring your own key" option?

LocalPilot is a complete agent, not just a model provider. You get the agent loop, tools, parallel agents, change review, skills, subagents, screenshots and MCP — and it also registers your local models with VS Code's Language Model API so other extensions can use them.

Can I use my existing Claude Code / Cursor rules and skills?

Yes. CLAUDE.md, AGENTS.md, .cursorrules, .cursor/rules/*.mdc, .claude/skills, .claude/agents and .github/copilot-instructions.md are all picked up automatically.
