# Work in the editor

LocalPilot is not only a chat. It works where your code is:

- **Inline edit** (`⌘⌥K` / `Ctrl+Alt+K`): select code, describe the change and review the diff in place. Accept or reject it like any other edit. In a focused terminal the same keys turn a description into a shell command.
- **Fix with LocalPilot**: the light bulb on an error or warning offers a fix from the local model.
- **Right-click > LocalPilot**: explain, refactor, document or write tests for the selection, or add it to the chat.
- **Terminal**: right-click a terminal and choose **Explain Terminal Output** or **Fix Failed Command** to send the last command and its output to the agent.
- **`@localpilot`** in VS Code's own Chat view uses the same local models, tools and skills.
