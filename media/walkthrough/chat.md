# The chat

Open LocalPilot from the activity bar or with `⌘⇧L` / `Ctrl+Shift+L`.

- **Ask** answers questions about your code without changing anything.
- **Plan** designs an approach and writes a checklist before touching files.
- **Agent** does the work: reads and edits files, runs commands, searches the web and delegates to subagents — asking for approval where you want it.

Use **@** to add context (`@workspace`, `@selection`, `@problems`, `@git`, open files, images or a screenshot) and **/** for commands such as `/model`, `/compact` or `/skill`.

Every edit the agent makes appears in the **Changes** panel with a diff, and can be accepted or rejected per file.
